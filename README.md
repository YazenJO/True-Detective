# DETECT — ديتكت

لعبة تحقيق عربية للموبايل. القضية الأولى: **«الملف الذي اختفى»**.

> **الاسم والهوية أصليان بالكامل.** لا علاقة للمشروع بمسلسل True Detective من HBO
> ولا بأي علامة تجارية قائمة. كل الأسماء والجهات والوقائع من نسج الخيال.

---

## التشغيل

افتح Unity Hub → المشروع `E:\GameDev\Projects\TrueDetective`
ثم **True Detective → Open Main Scene** واضغط ▶ **Play**.

في نافذة Game اختر **1080×1920 Portrait**.

أول تشغيل بعد إضافة ملفات جديدة: انتظر Unity تستورد الصور (شريط تقدّم أسفل يمين).

## بنية التجربة

```
مقدمة سينمائية  ← تُعرض مرة واحدة، قابلة للتخطي من أول إطار
      ↓
القائمة الرئيسية ──┬── ابدأ التحقيق
                   ├── القضايا     (١ متاحة · ٤ مقفلة تعرض خارطة الطريق)
                   ├── الأرشيف     (كيف تحقّق · ما يُثبت وما لا يُثبت)
                   └── الإعدادات   (صوت · مؤثرات · سرعة الحوار · مسح التقدّم)
      ↓
الجريدة → التكليف → التحقيق → الحل → الحكم
```

### حلقة التحقيق
```
افحص → اسأل → اربط → واجه → دليل جديد → أغلق القضية
```

## المسار الكامل للقضية

```
قاعة الأرشيف:  سجل العهدة (E1)  ·  استجواب سامر (E2)
غرفة الحراسة:  تسجيل الممر (E3)  ·  استجواب نادر (E4)
لوحة الربط:    E2 + E3 → «يناقض»
المواجهة:      سامر يقرّ بالعودة ويحدد الغرفة والوقت
نادر:          «بدي تسجيل غرفة الأرشيف بين 20:00 و 20:30» → E5
التقرير:       ٧ فراغات + الاستشهاد بـ E1 · E3 · E5
```

**جرّب الخطأ عمدًا:** اضغط «أغلق القضية» قبل الحصول على E5. الرفض ليس عقوبة — هو الدرس.

## إضافة قضية جديدة — بدون كود

١. انسخ `Resources/Cases/case01.json` → `case02.json`
٢. عدّل النصوص والمواقع والأدلة والشخصيات
٣. ضع خلفياتها في `Resources/Backgrounds` بأسماء تطابق حقل `background`
٤. **True Detective → Validate Case Files**
٥. غيّر `caseId` على كائن `TrueDetective` في الـInspector

المحمّل يرفض تلقائيًا: المعرّفات المعطوبة، الأدلة غير الموجودة، والتقرير غير القابل للحل.

## العربية — لا تلمس هذا

TextMeshPro **لا يصل الحروف العربية ولا يعكس الاتجاه**. `ArabicText.Fix()` يفعل الاثنين.

- كل نص يمرّ عبر `UIKit.Label()` أو `UIKit.SetText()`
- **لا تُسند نصًا إلى `TMP_Text.text` مباشرة**
- `isRightToLeftText` تبقى **مطفأة** — تشغيلها يعكس النص مرتين

### ⚠️ عند تغيير الخط
الخط الجديد **يجب** أن يغطي `U+FE70–FEFF`. خطوط ممتازة مثل Cairo و Tajawal تغطي 62%
فقط منه واللعبة تظهر بها كمربعات فاضية.

```bash
powershell -File Tests\check-fonts.ps1 -FontDir <مجلد الخطوط>
```

| الخط | التغطية | صالح |
|---|---|---|
| Amiri · IBM Plex Sans Arabic | 97% | ✅ |
| Cairo · Tajawal | 62% | ❌ |

## بناء Android

**True Detective → Build Android APK** → `Builds/TrueDetective.apk`

مضبوط مسبقًا: IL2CPP · ARM64+ARMv7 · عمودي · `com.truedetective.game`.
أول بناء يطلب مسار SDK/NDK/JDK — اتركها على "Installed with Unity".

## ما يعمل وما يحتاج تطويرًا

### يعمل
لوبي كامل · مقدمة سينمائية · حفظ التقدّم · إعدادات صوت وسرعة نص ·
حلقة تحقيق كاملة · بورتريهات تتغيّر بعد المواجهة · صور أدلة · خلفيات مرسومة ·
١٠ مؤثرات صوتية مولّدة · عربية صحيحة · قضايا بملفات JSON

### يحتاج تطويرًا
- **قضية واحدة فقط** — المحرّك يشيل أكثر، والأربعة الباقية عناوين لا محتوى
- **لا موسيقى** — المؤثرات فقط
- **لا تمثيل صوتي**
- **الانتقالات فورية** بين الشاشات عدا المقدمة
- **الخلفيات ثابتة** — لا حركة كاميرا ولا طبقات
